# Teaching modes

Pick the mode that produces the next useful evaluation artifact.

- **Explain:** contrast deterministic evidence with LLM judgment using one requirement.
- **Trace walk:** follow a completed run from transcript through `result.json`.
- **Socratic:** ask which promise failed, what evidence would prove it, and which oracle is
  cheapest.
- **Build:** create one persona, requirement, scenario, or invariant with the learner.
- **Review:** compare two runs and distinguish product regression from test instability.

Switch modes when the learner can repeat vocabulary but cannot point to an artifact, or when an
artifact exists but its evidence cannot be explained.
